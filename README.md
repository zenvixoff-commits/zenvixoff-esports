# ZENVIXOFF ESPORTS

A responsive static starter website for an independent gaming community.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Open repository Settings.
2. Select Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

## Current status
This is a frontend preview with sample tournament cards and sample leaderboard rows. It does not provide real accounts, database storage, tournament registration, payment processing, room credentials, or admin authentication. Those features require a secure backend and should be added before collecting player information or running actual events.

Paid-entry or prize events require checks for applicable laws, age restrictions, organizer legitimacy, and game publisher rules. This project does not implement betting or gambling.

ZENVIXOFF ESPORTS is an independent community project and is not affiliated with Garena or Free Fire.
